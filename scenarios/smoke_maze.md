# Smoke Test: Maze Generator & Solver

**Difficulty:** Easy
**Expected steps:** 3-5
**Tools exercised:** shell, write_file, done
**Validates:** Basic plan → execute pipeline

## Goal

Write a Python script that generates a random 20x20 maze and solves it with BFS, printing the solution path as ASCII art. The maze should use '#' for walls, ' ' for paths, 'S' for start, 'E' for end, and '.' for the solution path. Run the script and show the output.
