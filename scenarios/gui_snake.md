# GUI Test: Snake Game

**Difficulty:** Medium
**Expected steps:** 10-20
**Tools exercised:** shell, write_file, screenshot, gui tools
**Validates:** Virtual display, screenshot pipeline, GUI interaction

## Goal

Build a Snake game in Python using pygame. The game should have:
- A grid-based playing field
- Snake that grows when eating food
- Score display
- Game over on wall/self collision
Run it on the virtual display (DISPLAY=:99) and take a screenshot to verify it renders correctly. Put the code in /home/agent/snake-game/.
