# Light Test: URL Sitemap Extractor

**Difficulty:** Medium
**Expected steps:** 10-15
**Tools exercised:** shell, write_file, edit_file, web_fetch
**Validates:** Multi-file project, testing, iterative development

## Goal

Build a Python CLI tool that takes a URL as input, fetches it, extracts all links from the HTML, and outputs a sitemap as JSON. The JSON should include each link's URL, anchor text, and whether it's internal or external. Include unit tests using pytest and run them. Put everything in /home/agent/sitemap-tool/.
